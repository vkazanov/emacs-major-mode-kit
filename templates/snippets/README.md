# Snippets

These are copy/adapt references for common generated-mode patterns. They are not
runtime libraries and do not override the numbered skill documents.

Use a snippet only after opening the relevant skill. Replace `LANG`, `LANGNAME`, and
language-specific regexps or commands with facts from the current facts source.

Each snippet should be paired with focused ERT coverage in the generated mode test
file. Do not use snippets to invent missing language semantics, external tools,
tree-sitter grammars, or formatter commands.
